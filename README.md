# 🧮 Tkinter Calculator (Python)

A simple graphical calculator built using **Python** and **Tkinter**.  
This project demonstrates basic GUI programming, event handling, and simple logic implementation in Python.

---

## 📌 Features

- Basic arithmetic operations:
  - Addition (+)
  - Subtraction (-)
  - Multiplication (*)
  - Division (/)
- Clear all input (`c`)
- Delete last character (`<--`)
- Error handling for invalid expressions
- Clean and simple GUI using Tkinter

---

## 🛠️ Technologies Used

- **Python 3**
- **Tkinter** (built-in Python GUI library)
